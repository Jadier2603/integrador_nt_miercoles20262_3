# integrador_nt_miercoles20262_3
Proyecto Integrador Nuevas Tecnologias 

## Cómo generar los datos de retos

Desde la carpeta raíz del proyecto:

```bash
pip install -r requirements.txt
python src/exportar_retos.py
```

Esto crea `data/crudo/retos_sucio.csv`, `retos_sucio.xlsx` y `retos_sucio.json` (500 filas, 9 columnas, con datos sucios a propósito).
